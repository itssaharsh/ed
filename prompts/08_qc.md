# Stage 11 — Quality gate

The stage the old pipeline did not have. When its LLM failed completely, it uploaded a stock clip
of "person" with a placeholder script. **This gate exists so that can never happen again.**

Variables: `{{SCRIPT}}` `{{BASELINE}}` `{{DURATION}}` `{{SHOT_COUNT}}`

---

## Fail-closed

If this gate cannot establish that the video is good, **nothing is published.** A missed upload
slot costs nothing. A bad upload costs channel reputation and, under the mass-produced content
policy, potentially monetisation.

## Part A — mechanical checks (code, not model)

Run before the judge. Any failure aborts the run immediately; no judge call is made.

| Check | Threshold |
|---|---|
| Audio duration | 20s ≤ d ≤ 60s |
| Video duration matches audio | within 0.5s |
| Shot count | ≥ 4 |
| Every shot has a real generated image | no placeholders, no repeats of one image |
| Caption count | ≥ 15 word cues |
| Word count | 60 ≤ w ≤ 140 |
| Loudness | integrated -16 to -13 LUFS |
| No silence > 1.2s anywhere | — |
| Script is not byte-identical to any previous script | — |
| Premise similarity vs. store | below dedup threshold |

## Part B — the judge

Same pairwise machinery as stage 2, for the same reason: absolute quality scores from an LLM are
noise. Instead of scoring the script, compare it against a **fixed baseline script** of known
mediocre-but-acceptable quality.

The question is: **is this better than the floor?**

{{BASELINE}}

versus the candidate:

{{SCRIPT}}

Judge it on the criteria from `prompts/02_tournament.md`, in the same order: surprise, specificity,
recognition, compression, cleanliness.

A candidate that **loses to the baseline is rejected.** It does not get published as "good enough".

## Part C — the veto checks

Independent of the comparison. Any `true` here rejects the run outright, regardless of how funny
the judge found it.

- `explains_its_own_joke` — states the mechanism after the punchline
- `punch_is_not_last` — the funniest line is not the final line
- `ai_tell_cluster` — **three or more** of the banned constructions in `prompts/00_voice.md`
  converging in one script. One occurrence is not a veto; the research is explicit that individual
  tells have innocent human causes and it is the cluster that reads as machine-written.
- `generic_premise` — the script would work unchanged with the nouns swapped out
- `no_recognisable_truth` — absurd without being anchored to anything real
- `unsafe` — targets a real named private individual, or is hateful rather than comic

## Output

Strict JSON. No prose.

```json
{
  "beats_baseline": true,
  "deciding_criterion": "specificity",
  "why": "one concrete sentence",
  "vetoes": {
    "explains_its_own_joke": false,
    "punch_is_not_last": false,
    "ai_tell_cluster": false,
    "generic_premise": false,
    "no_recognisable_truth": false,
    "unsafe": false
  },
  "weakest_line_index": 3,
  "one_fix": "the single change that would most improve this — recorded for tuning, not applied automatically"
}
```

**Publish if and only if** `beats_baseline == true` **and** every veto is `false` **and** all of
Part A passed.
